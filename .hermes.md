No shadcn, no Radix.

Native later: SwiftUI + `Image(systemName:)`. Do not ship Apple SF Symbols on the public site.

## Rules

- Holdings stay in the browser. Quotes API gets **symbols only**, never holdings.
- Do not change the visual language. Apple HIG iOS/Mac 26/27 Liquid Glass only.
- Glass on chrome + widget-glass `.panel` cards. Inset grouped **lists** stay opaque.
- Size class, not device: compact `<768` dock; regular `≥768` sidebar; **960px** leading measure.
- Tax/compare/projection is illustrative, not advice.
- Akahu tokens only in `.env.local`. Never paste tokens in chat. Never commit `.env`.
- KiwiSaver: CSV/manual only. No password scrapers.
- Do not scrape apple.com / Wallet / Apple Card CSS.
