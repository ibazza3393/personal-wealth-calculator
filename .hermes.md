## Rules

- Holdings stay in the browser. Quotes API gets **symbols only**, never holdings.
- Do not change the visual language. Apple HIG iOS/Mac 26/27 Liquid Glass only.
- Glass on chrome + widget-glass `.panel` cards. Inset grouped **lists** stay opaque.
- Size class, not device: compact `<768` dock; regular `≥768` sidebar; **960px** leading measure.
- Tax/compare/projection is illustrative, not advice.
- Akahu tokens only in `.env.local`. Never paste tokens in chat. Never commit `.env`.
- KiwiSaver: CSV/manual only. No password scrapers.
- Do not scrape apple.com / Wallet / Apple Card CSS.

## Product (local now, cloud later)

Barry intends to roll this out as a product. Local-first is the current slice, not the ceiling.

Do not build multi-tenant infra until he asks. Do keep the door open:

- Domain types in `lib/domain.ts` stay the contract. UI never imports Akahu/Basiq shapes.
- LocalStorage remains source of truth until an explicit signed-in sync exists.
- Quotes already run on a server (tickers only). A future backend adds auth, per-user bank tokens, optional encrypted snapshot sync — not a rewrite of the client.
- Akahu Personal App (`.env.local`, 1 user) is Barry-only. A product needs Akahu’s multi-user OAuth; tokens live per user on a private server, never in the public client or a shared Vercel env.
- In-app Grok/Hermes chat: local Hermes sidecar is fine for Barry. A product cannot share one SuperGrok OAuth; it needs a billed API with per-user isolation. Chat must not auto-send holdings.
- Public Vercel stays free of bank tokens, xAI user tokens, and portfolio payloads.
